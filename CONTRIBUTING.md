# Contributing

The client code is generated by Fern from `spec/affinity.openapi.json`. Do not edit generated files
(see AGENTS.md for the list); change the contract upstream or the Fern configuration instead.

## Regenerate

Needs Docker, Node and jq. No Fern account or token is used.

```sh
cp <path-to-new-contract>.json spec/affinity.openapi.json   # only when the contract changes
./scripts/generate.sh
```

The script adds Fern's method names and pagination to a copy of the contract
(`scripts/prepare-spec.jq`), runs Fern in Docker, replaces the generated files and writes
`generation.json`. Running it twice gives the same tree.

## Verify

```sh
./scripts/generate-check.sh
docker run --rm -u "$(id -u):$(id -g)" -e GRADLE_USER_HOME=/tmp/gradle -v "$PWD":/work -w /work \
  gradle:8-jdk17 sh -c './gradlew --no-daemon build && ./gradlew --no-daemon -p tests test installDist'
```

Then run the smoke test against staging with a Test key (README "Build and verify"). Update
README.md, CHANGELOG.md and the smoke test when the generated method names change.
